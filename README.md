# VIDLIK [Pomodoro Time & Task Management Application]

**VIDLIK** is a productivity-focused web application designed to help users manage tasks, track working hours, and maintain focus using the **Pomodoro technique**.

The project demonstrates practical implementation of **authentication flows, task management, time tracking, and full-stack development** with a clean and intuitive user experience.

🔗 **Live Demo:** https://vidlik.vercel.app

<br>

## 💡 What Problem It Solves
VIDLIK helps users stay focused and avoid burnout by breaking work into structured intervals with scheduled breaks, while also providing task tracking and personalized productivity settings.

<br>

## 🧠 Technical Highlights
- Built a full-stack application with **Angular and Node.js**
- Implemented **Pomodoro timer logic** with configurable rounds and breaks
- Developed secure **user authentication**, including Google Authentication
- Created dynamic task management with real-time status updates
- Designed a responsive UI focused on simplicity and usability
- Integrated MongoDB for scalable data persistence

<br>

## 🛠️ Tech Stack
**Frontend:** Angular, TypeScript, RxJS, SCSS, Bootstrap  
**Backend:** Node.js  
**Database:** MongoDB  

<br>

## ✨ Key Features
- **Pomodoro Timer:** Configurable work sessions, breaks, and rounds  
- **Task Management:** Create, edit, and track to-do items  
- **Time Tracking:** Monitor work duration per task  
- **Authentication:** Email/password and Google Authentication  
- **Personalization:** Custom productivity settings for registered users  
- **Responsive Design:** Optimized for desktop and mobile use
